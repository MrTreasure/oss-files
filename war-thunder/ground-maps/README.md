# War Thunder ground maps

55 base maps, 55 terrain contour SVG overlays, 77 DOM preview thumbnails, and 6 point icons.

Original base maps are unchanged. Contour SVG syntax is compacted without changing numerical coordinates or line geometry. Filenames contain SHA-256 prefixes; full hashes and source hashes are in manifest.json. Game imagery remains the property of its respective rights holders.

Used by https://github.com/MrTreasure/war-thunder-workbench
